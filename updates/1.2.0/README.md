# KEFIRIZ 1.2.0

This release adds KEFIRJS Updater to Horizon edition 786. The app follows Basic White and Basic Black. In KEFIRIZ Homebrew it appears under Torrent. KEFIRIZ System also has an Updater button. Hold R + X when launching a game from Nintendo HOME to open the updater directly.

The app displays the installed version, candidate version and release notes before installation. Each update has an Ed25519 publisher signature and SHA-256 digests for the files it installs. Interrupted updates have a recovery journal on the card. Recognized files from the previous Kefir Updater are backed up during migration. Personal files with different contents are preserved.

The on-console upgrade starts with KEFIRIZ 1.1.0 on Horizon 20.5.0 / Kefir 786. The complete Windows distribution also supports an existing matching Kefir 786 microSD. [Release downloads](https://github.com/Stasan-minecraft/kefirjs-updates/releases/tag/v1.2.0)
